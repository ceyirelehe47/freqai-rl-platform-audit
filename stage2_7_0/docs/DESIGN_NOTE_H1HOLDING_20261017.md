## 一、可辨识性与固定六状态
H1-flat 门控项仅约束 p_flat=pH+pR·A0,**无法单独识别
HOLD/REBAL0 配比**;两者从 flat 出发均无交易费用、相同期末
经济结果。**这是该门控项与该状态的等价性,不声称完整 PPO/
熵目标对所有参数化严格等价。HOLD 1943 是全程 2112 步计数,
不能称为 rem1 计数。**

六状态固定为 **s=±1×{flat,正确已有 e=s,错向已有 e=−s}**,
c=1、q=1、g=0、remaining=1、horizon=32;**w0 明确取 1**。
账户由**原 TwoSidedLinearLedger.apply_target_ratio(±1,P)
实际建仓生成**(非虚构 open(w) 接口);记录 cash/qty/
avg_entry/fees/fills 及当前 **E0=equity(P)** 作新段净 log
分母;已发生入场费保留不在新段重复计费。原 Ledger 为现金
结算线性合约,equity(P)=cash+qty·(P−avg_entry),**禁止
cash=E−qP**。已有 |e|=1 时 solvency=1;**flat 观测
solvency 按原规则封顶 40,三账户组不固定同一 solvency**。

## 二、原账本的精确费用与终值
当前价格 P、当前权益 E0、旧数量 Q、执行后数量 x、f=.001。
零滑点/tick/funding 下,**调仓费=f·P·|x−Q|,不是任何
REBAL 都先平旧仓再开新仓**:
E_after=E0−f·P·|x−Q|,x·P=w·E_after。
若 η=sign(x−Q),固定分支解
**x=w·(E0+η·f·P·Q)/(P·(1+η·f·w))**(再验证分支;x=Q
无成交)。实际实现继续以原 **Ledger._solve_q_new/
apply_target_ratio** 为准。
一期 r 后终端清仓:
**E_final(x,r)=E0−f·P·|x−Q|+x·P·r−f·P·|x|·(1+r)**。
因此 **HOLD 与 REBAL 到"当前同一敞口"可严格同数量/零调仓
费等价;HOLD 仍有期末清仓费;仅反手时 |x−Q|=|Q|+|x|,
不能把该式套给同向减仓/原仓保持**。

固定 g0 下 r=mu+√3·.03·U,U 均匀于 [−1,1],mu=s·.0012。
**完整条件分布已由冻结生成机制给定,其高阶矩不是额外隐藏
信息,更不需要未来实现收益标签。** 令 u=x·P/E0,e=Q·P/E0;
|w|≤1、|e|≤1 给 |u|≤1,|r|<.054。终值比至少
1−.002−.054−.001054>.94;期内偿付余量远高于 .05,
维持保证金风险不介入。**终值对 x 为凹函数(负绝对值费用),
正值域中 log 递增且凹,故期望 log 凹;不能笼统称全域仿射。**

## 三、三类解析最优经济事件
1. **flat**:沿用已验一期费用证明,非零开仓的期望 log 严格
   小于 0;维持 flat 事件为 HOLD 或 REBAL0,概率 pH+pR·A0。
2. **错向已有 Q·mu<0**:立即平仓得 E_flat=E0−f·P·|Q|。
   若 x 仍错向,(x−f·|x|)·mu≤0 且 |x−Q|+|x|−|Q|≥0,
   故 E[E_final]≤E_flat(x≠0 严格);若 x 反向为正确方向,
   期望差=P·|x|·[sign(x)·mu−f·(2+mu)]<0(因 .0012<
   .001·1.9988)。Jensen 给所有非零 x 的期望 log 劣于立即
   平仓。**事件为 REBAL0,概率 pR·A0;HOLD 不是平仓。**
3. **正确已有 e=h=s=±1**:令 y=h·x·P/E0,所有可行 y≤1。
   对 0≤y≤1:E_final/E0=(1−f)·(1+y·z),
   z=(h−f)·r/(1−f)。多头 z=r;空头 z=−k·r,
   k=(1+f)/(1−f)<1.003。因此 E[z]≥.0012,
   E[z²]≤1.003²·(.03²+.0012²),z>−1.003·.054,
   **E[z/(1+z)]≥.0012−1.003²·(.03²+.0012²)/
   (1−1.003·.054)>0**。期望 log 全域凹,y=1 左导数正,
   **维持当前数量是固定可行域的最优事件;HOLD 与 REBAL
   当前 h=±1 均可,概率 pH+pR·A_h。这里是相对其他可行动作
   的优势,不声称含不可避免清仓费的绝对净 log 为正。该证明
   仅用于上述固定六状态,不扩为任意账户/幅度/风险档标签。**

A−/A0/A+ 均用**冻结 P0 merged_atom_logp 给出的合并原子**
(含 Beta 零/尾单元),不以条件均值 m 或 raw mix_zero 替代
事件概率;不任意规定必须 HOLD 或必须 REBAL 同目标。
**三项控制均有经济依据:始终 HOLD 失败于错向清仓组;始终
REBAL0 失败于正确持仓组;始终沿 s 满仓失败于 flat 组。**
