## 一、同一原账本的解析依据
令 f=.001,a=|w|,起点合法 flat、当前价格 P、权益 E0、
remaining=1。按原双侧费用精确到目标敞口 w 后:
**E_open/E0=1/(1+f·a),quantity=w·E_open/P**。
一期收盘价 P·(1+r),终端平仓按实际数量及该收盘价付费:
**R(w,r) = E_final/E0 = [1+w·r−f·a·(1+r)]/(1+f·a)**。
**不能写成 (1+w·r)·(1−f·a)/(1+f·a)**——w=.5,r=.01 时
正确值 **1.0039930034982509**,错误乘积 1.0039955022488756,
两者不等(v1 乘积式错误,撤回)。

当前可见 (c,s,q,g) 与冻结生成机制给 **mu=s·c·q·.0012**
——这是**已知条件均值,不是未来实现收益**(非未来信息)。
不必逐题代入 mu,仅用 |mu|≤.0012:
**E[R]−1 = [w·mu−f·a·(2+mu)]/(1+f·a)
 ≤ a·(.0012−.001·1.9988)/(1+.001·a) < 0(a>0)**。
固定价格支撑与 w∈[−1,1] 下终值为正,Jensen 给
**E[log R] < log 1 = 0**;w=0 则为 0,flat HOLD 亦为 0。
因此**该域的正确经济标签是"期末保持 flat"**(HOLD 与
REBAL0 均可);**不从未来收益筛标签**,不声称精确逐点 Q,
不将证明推广到已有仓位/H32。

## 二、最小实际分布目标
pH=P(HOLD);p0=P(w=0|REBAL) 采用**冻结 P0 的合并零原子
质量**——B 分布中 **p0=mix_zero+mix_cont·b0**(b0=连续
Beta 的零单元质量;不能只取 raw mix_zero,也不能把 aux
条件均值 m 当概率或经济收益)。**p_flat=pH+(1−pH)·p0**。

**唯一固定 H1 监督候选**:
**L_gate = −mean(log(p_flat))**,限定**合法 flat 且
remaining=1 两行输入**。稳定实现复用冻结 branch_logp 与
merged_atom_logp:
**log_p_flat = logaddexp(log pH, log pREBAL + log A0)**。
无模型自信阈值、无费用与 m 跨量纲比较、不新增概率毕业门
(v1 的"自身 m 伪经济门"已移除)。若后续改选一侧 hinge,
正确方向是 relu(target−p_flat)²且 target 须事前候选标注;
**本计划只用上述无概率阈值目标,不扫两种形式**。

H32 原方向损失不变,仍仅是条件方向教学,**未认证 H32 最优
开仓或幅度**。H1 标签不施加给 H32、已有仓位或其它期限。
共享参数仍可能产生跨状态影响——**独立报告,不声称域掩码
自动保证无遗忘**。

- **保留原 256 方向预教学整段**——不能一面把其中 4 批替为
  新 gate、一面称与旧 post_aux 同起点(v1 自相矛盾,撤回)。

  boundary_post_aux.pt 核参数/Adam/全部已记录 RNG 与
