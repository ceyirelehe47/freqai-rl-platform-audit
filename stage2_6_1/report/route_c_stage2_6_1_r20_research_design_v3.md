## 0. 相对 v2 修复了什么(独立审查 §四 对应)

1. **最低K公式**:v2 用 `z_0.95 + z_0.90 = 2.9264051924960723` 作
   90% 判据,连续边界实际只有 80% 功效。正确达到 90%(alpha=0.05)
   需要 `z_0.95 + z_0.95 = 3.289707253902943`。零偏差功效统一为
   `max(0, 2*Phi(Delta*sqrt(K)/s - z_(1-alpha)) - 1)`,裁剪到 [0,1]。
2. **最低K算法**:同一功效函数自 K=1 向上逐点搜索,并逐点验证
   一切 j<K 未达标(无稀疏K表跳过)。
3. **两张表分开**(§3):"分析SE已按 rho 修正后的功效"与"不修正但
   真实SE放大时的假等效概率"不再混写。
4. **SE 模型**(§2):等权平均 `sqrt(sum(SE_k^2))/K`;共享解析锚只
   加一次、不随K缩小;bootstrap 20000 次只界定重抽样数值误差。
5. **行动分类**(§4):互斥主类别 + 独立方向标签;"等效界内但显著
   非零"不再触发相冲突动作。
6. **K 不迁就旧值**:K 由目标功效 + 选定 rho 场景推导
   (§5),不是为了保住 v2 的 K=8。

## 1. 唯一主分析路径(C02/C06)

**主路径一句话**:每坐标有符号偏差 δ_k = p_analytic −
recall(validation_k) 的正态点估计 + R19 同口径 block-cluster
bootstrap SE;聚合 SE = `sqrt(sum(SE_k^2))/K`(等SE特例 = s/√K),
共享解析锚为显式条件化可选项;判定 = 聚合均值对称 TOST
(双侧 90% CI 整体落入 ±Delta,α=0.05);设计/功效用已知SE正态
公式,SE 估计误差以 rho∈{1.0,1.25,1.5} 敏感性覆盖。

- 方向约定(沿 v2):δ>0 表示实测 recall 低于解析预测;R19 观测
  δ=+0.004500(z=+2.318,单坐标,仅历史描述)。
- `VALID_SE = 0.0019410552950364546` 是 R19 原件 500-block 锚的
  **只读历史输入**,不是本轮观测,也不是已知真值。
- 已知SE正态模型是主路径的**设计层近似**:实际分析把 bootstrap
  估计SE代入同一区间式,其与已知SE情形的操作特性差异已披露,由
  rho 敏感性与保守规划部分覆盖;**不引入 t 分布/第二套竞争框架**。
- 总体:预注册 K 个新坐标(audit namespace/attempt,批准前列出
  清单防挑样)上的平均偏差 δ̄。事件←块←语料←坐标层次不变;
  坐标间独立性是**设计假设**(预注册新种子),正相关处理见 §2.3。

## 2. 标准误模型(C03)

### 2.1 等权平均基线与反例

独立、不同 SE_k 时:`SE(δ̄) = sqrt(sum(SE_k^2))/K`;
`mean(SE_k)/sqrt(K)` 仅在全部 SE_k 相等时成立。反例
(SEs = {0.001, 0.003}):正确 = **0.0015811388300841897**,
错误 = **0.001414213562373095**(系统性低估约 10.6%)。

### 2.2 共享解析锚:只加一次,不随K缩小

若每个 δ_k 共享同一不确定解析锚(方差 Var(anchor)),
`Var(δ̄) = sum(s_k^2)/K^2 + Var(anchor)` —— 锚只进入一次。
主案(K=11, rho=1.5)下锚SE敏感性(JSON D 表):

| 共享锚SE | 聚合SE | Δ/SE | 零偏差功效 |
|---:|---:|---:|---:|
| 0 | 0.0008778752878593436 | 3.417 | 0.9236864589708058 |
| 0.0002 | 0.0009003693803290545 | 3.332 | 0.9084182189232235 |
| 0.0005 | 0.0010102796746614896 | 2.969 | 0.8147031587920892 |

90% 目标的锚SE盈亏平衡值 = 0.000246902562297993。**主分析按
"p_analytic 条件固定"处理**(历史依据:权重源对照移动 p ≤ 6e-6
≈ 0.3% SE;归因报告),若审查方不接受该条件化,锚SE必须在定 K
之前单独量化——上表说明锚 ≥ 0.0005 时 K=11 已不保 90%。

### 2.3 跨坐标相关(显式公式,不糊弄)

等SE、等两两相关 rho_c 时 `SE(δ̄) = s*sqrt((1+(K-1)*rho_c)/K)`;
一般情形须用完整协差阵表述。K=11 放大因子:rho_c=0.05→
1.224744871391589,0.1→1.4142135623730951,0.2→
1.7320508075688772。主设计假设 rho_c=0(新 namespace/attempt/
种子),**该假设不在 rho 敏感性覆盖范围内**。

### 2.4 bootstrap 次数只界定数值误差

`1/sqrt(2*20000) = 0.005`(0.5%)是**给定固定原始 blocks 时,
bootstrap SE 估计本身的重抽样数值误差**的近似上界(正态理论
SD 估计的相对MC误差 ~1/sqrt(2B))。它**不覆盖**:有限原始
blocks(500/语料)的 SE 统计不确定性、跨坐标/实现级散布、
percentile bootstrap 模型误差。这些由 rho 敏感性与保守规划
部分覆盖,不能靠加 bootstrap 次数消除。v2 把 0.5% 当作 SE 不
确定性的整体度量是口径错误,本版改正。

## 4. 行动分类(C05):互斥主类别 + 方向另报

主类别(互斥,四选一):`within_equivalence_bounds` /
`beyond_positive_margin` / `beyond_negative_margin` /
`inconclusive`(其余一切:触界、跨界、缺数据)。方向标签独立另报:
`positive` / `negative` / `not_resolved`。触界保守归不决;
区间触零方向归 not_resolved。

**工作示例**(K=8, δ̂=0.0015, SE=VALID_SE, α=0.05):
CI90 = [0.00037119176088350756, 0.0026288082391164925] ⊂ (−0.003,
0.003) ⇒ magnitude=`within_equivalence_bounds`,
direction=`positive`。报告口径:"检测到正向小偏差,且在待审
等效界内"——**不触发**"超过重要界→必须校准"动作。
`beyond_*` 才转校准路线(研究建议,不自动授予正式实验权限);
`inconclusive` 只如实报不决,不得改称"涨落主导"。
"数值上偏差非零"与"等效界内"可同时成立,不再当冲突。
多项检验的复合错误率不自动等于单一 5%,如需复合策略另行申报。

## 5. K 与每坐标 blocks 的推导(C06)

**K**:目标 = 零偏差功效 ≥ 90%(α=0.05);规划场景 =
rho=1.5(保守;历史三代码态 z 散布 sd_z≈1.556>1 与 SE 低估至
1.5× 相容,无法排除)。同公式向上搜索得 **K=11**
(功效 0.9236864589708058;K−1=10 功效 0.8933540960149853<0.90)。
K=8 出现在 §3 只作对照:**rho=1.5 时 K=8 功效仅 0.795724852849675,
不达标**;若审查方接受 rho≤1.25 为充分规划场景,最低 K=8。
聚合SE(等SE特例)= 0.0008778752878593437。

**每坐标每语料 blocks = 500**(与 R19 锚同规模)。经验尺度假设
`SE(B) = VALID_SE*sqrt(500/B)`(单点锚外推,指数未经第二锚点
验证——假设已披露)。若改为在固定SE目标下用 blocks 抵消 rho:
`B = ceil(500*rho^2)` → rho=1.00/1.25/1.50 时 500/782/1125
(SE 例:B=125→0.003882110590072909,B=2000→
0.0009705276475182273)。零偏差判据比 `Delta*sqrt(K)/SE(B)` 只
依赖乘积 K·B(主案 K·B=5500,比值 5.126012842864084;(5,1100)、
(10,550) 等价)——总预算固定时 K/B 分配是设计选择:**多坐标
还能覆盖跨坐标/实现级散布,加blocks只压缩单坐标重抽噪声**,故
选 (K=11, B=500),不外推尺度律。

固定 seed=20260925、100,000 次/情景、抽象正态世界(JSON H 表,

**不证明**该模型对真实生成器/簇结构/解析锚成立;不用同一公式
生成的"真值"冒充独立验证。
